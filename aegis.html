The engineering thesis

Replace brittle single-turn chatbot answers with an auditable, multi-agent pipeline governed by state machines and strict schema contracts.

Aegis rejects the naive approach of prompting an LLM with "is this true?". Instead, it operates as a structured threat-intelligence platform designed to expose the difference between inorganic narrative attacks and organic sentiment shifts. The core architectural challenge is system orchestration: ingesting claims without duplicate inference, running parallel quantitative market scans, decoupling evidence discovery from verdict synthesis, enforcing JSON Schema contracts, and gracefully handling model rate limits.

The deployed architecture integrates a high-performance Vanilla JS single-page interface, a resilient Netlify serverless edge proxy with multi-key rotation, an asynchronous FastAPI backend on Render, recurring RSS ingestion loops, and Supabase PostgreSQL with vector similarity indexing.

Application plane

FastAPI + BackgroundTasks

API requests immediately return a unique tracking job. Asynchronous background workers transition the claim through pending → in_progress → completed | failed states with persisted diagnostic logs.

Edge gateway

Netlify Serverless Proxy

Browser clients call /.netlify/functions/gemini. The proxy protects API credentials, manages multi-key rotation, handles exponential backoffs, and seamlessly falls back from Gemini 2.5 Flash to 2.0 Flash.

Market intelligence

Scout Agent (Quantitative ML)

Fetches historical closing prices and trade volume via Yahoo Finance proxies. Calculates rolling standard deviations and Z-scores to distinguish inorganic market shocks from natural volatility.

Data & Vector plane

Supabase PostgreSQL + pgvector

Claims, verified rebuttals, and extracted evidence are stored with vector embeddings for semantic similarity search, cross-claim deduplication, and forensic audit history.

Runtime workflow

Deterministic execution behind every claim

01

Canonical fingerprinting before spending model tokens

The ingestion pipeline trims whitespace, strips punctuation variations, normalizes case, and generates a SHA-256 cryptographic hash. If the hash exists in the Supabase cache, the existing verified record returns instantly with 0ms LLM latency.

normalized_text → sha256_hash → cache_hit ? return : dispatch_job
02

Asynchronous job lifecycle management

FastAPI acknowledges submissions within 80ms by issuing a job ticket. The claim worker executes independently, updating the database record as stages complete so clients can poll or stream status updates.

pending → researching → synthesizing → completed | failed
03

Decoupled Research → Investigator swarm

The Research Agent is constrained to gathering supporting and contradictory evidence without passing judgment. The Investigator Agent then consumes this evidence as a structured payload, evaluating source credibility and generating a calibrated verdict (Confidence 0–100%, Severity Level, Category, and Structured Rebuttal).

04

Schema validation & retry resilience

Model responses are forced into an explicit JSON Schema. If an inference output violates the contract, a retry interceptor reprompts with temperature decay, guaranteeing that frontend UI parsers never encounter unexpected null or malformed fields.

05

Transparent backend wake-up & source indicators

The review interface explicitly informs operators when cold-start cloud containers are warming up, displaying clear badges for live verified data, vector-cached results, or benchmark dataset fallbacks.
