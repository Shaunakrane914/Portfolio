Overview

Aegis is a production-grade misinformation detection platform built around the concept of cooperative AI agents — each specialised for a distinct task in the verification pipeline. Rather than a single monolithic model, Aegis orchestrates a network of agents that communicate and handoff work asynchronously, achieving real-time throughput at scale.

The system was built to address a genuine problem: the spread of false claims across social media faster than any manual fact-checking team can respond. Aegis operates autonomously 24/7, ingesting claims, cross-referencing trusted sources, and outputting a confidence-scored verdict.

How It Works — Step by Step

01

Claim Ingestion

A claim is submitted via the web UI or REST API endpoint. The CORE orchestrator validates the input, deduplicates against the cache, and routes it to the pipeline queue.

POST /api/check → { "claim": "vaccines contain chips" }
02

Source Fetching

The FETCH Agent concurrently scrapes 8 trusted sources — WHO, CDC, Reuters, Snopes, PolitiFact, AP, AFP, and Wikipedia — using async HTTP requests. Returns raw evidence in <120ms average.

8 concurrent requests · BeautifulSoup parsing · 120ms avg
03

LLM Analysis

The ANALYZE Agent feeds the raw evidence + original claim to the LLM (Gemini API). The LLM extracts key statements, identifies logical inconsistencies, and produces structured analysis JSON.

Gemini API · structured output · claim_score: 0.0–1.0
04

Cross-Verification

The VERIFY Agent cross-references the LLM analysis against a curated fact-check dataset. Multiple signals are combined using a weighted confidence model to eliminate hallucination risk.

dataset lookup · weighted scoring · anti-hallucination filter
05

Verdict Output

The VERDICT Agent generates a final response: TRUE / FALSE / UNVERIFIED with a confidence percentage, supporting evidence citations, and a plain-English explanation. Total pipeline: <250ms.

{ verdict: "FALSE", confidence: 0.94, sources: [...] }
Engineering Problems Solved

Challenges & Solutions

Problem

Real-time latency in multi-agent pipeline

Sequential agent execution produced unacceptable latency (800ms+) — one agent waiting for another blocked the entire chain.

Solution

Async FastAPI + concurrent agent dispatch

Rewrote orchestration using asyncio + FastAPI with concurrent source fetching. The FETCH agent now fires 8 requests simultaneously, bringing latency to <250ms.

Problem

LLM hallucinations generating false verdicts

Early versions relied solely on LLM output, which sometimes confidently stated incorrect verdicts when source material was ambiguous.

Solution

Multi-source verification layer

Added a dedicated VERIFY agent that cross-checks LLM analysis against a curated fact-check dataset. LLM verdict must align with >60% of source signals to avoid UNVERIFIED output.

Problem

Duplicate claims flooding the pipeline

Viral misinformation causes the same claim to be submitted thousands of times, creating redundant processing load.

Solution

Semantic deduplication cache

Implemented a semantic similarity cache — new claims are embedding-compared against recent claims. Matches serve cached verdicts instantly, eliminating 70%+ of redundant processing.
